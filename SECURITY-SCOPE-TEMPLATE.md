# Politique de périmètre pour les audits

À compléter par le propriétaire du SaaS avant tout test actif.

- Organisation/propriétaire :
- Domaines autorisés :
- Adresses IP autorisées :
- Environnements autorisés (local/staging/production) :
- Comptes de test :
- Fenêtres de test :
- Limites de débit :
- Exclusions explicites :
- Contact d'urgence :
- Confirmation d'autorisation :

Par défaut, les skills doivent se limiter à l'analyse du dépôt local et des fichiers de configuration fournis. Aucun scan actif d'un domaine, d'une IP, d'un compte ou d'une infrastructure ne doit être lancé tant que le périmètre et l'autorisation ne sont pas explicites.
